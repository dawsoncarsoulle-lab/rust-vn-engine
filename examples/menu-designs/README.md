# Editable menu designs

`Sobre`, `Science-fiction` and `Illustré` preserve the native editor's saved
layouts, pages and interactions. Each project has a matching `.rvnuitheme`
package. The legacy illustration and all packaged media have been removed
from these public fixtures; add your own licensed illustration in the editor.

These are menu-layout examples, not the full “Letters at Dawn” game. Their
serialization, resource independence and responsive layouts are checked by
`rvn_ui/tests/shipped_designs.rs`.
