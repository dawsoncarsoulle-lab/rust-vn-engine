# Text-only starter

Run `rvn check .` to validate this project. Edit `scripts/main.rvn`, then use
the CLI run/export commands to play it. This starter intentionally includes
no images or audio. Add your own media with appropriate redistribution rights.

The starter script and theme are MIT-licensed with the engine. They are not
the complete “Les lettres de l’aube” example shipped with the separate editor.
